BANK MANAGEMENT SYSTEM - SIMPLE CONSOLE PROJECT

Technologies: Core Java, OOP, JDBC, MySQL

Features:
1. Create account
2. View account details
3. Deposit money
4. Withdraw money
5. Check balance
6. Transfer money (JDBC commit/rollback)

Setup:
1. Install JDK 8+ and MySQL.
2. Run database.sql in MySQL Workbench.
3. In DBConnection.java, change PASSWORD to your MySQL password.
4. Download MySQL Connector/J and add its JAR to your project libraries.
5. Run Main.java.

Files:
Main.java          - Console menu and input
BankAccount.java   - Account model
BankOperations.java- Banking operations and SQL
DBConnection.java  - JDBC connection
database.sql       - Database schema

Educational project only. It is not a production banking system.
